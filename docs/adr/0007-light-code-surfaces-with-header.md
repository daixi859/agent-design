# 代码面随主题回暖光，统一表面语言并加头部栏

用户反馈常暗代码块与暖纸面、三层折叠嵌套不和谐。决定：代码面改回**随主题**——浅色主题用暖调代码面（`#eceae1` + one-light 高亮），深色主题维持深面；本条款修订 ADR-0005 中「代码块常暗」的部分。同时统一所有代码表面（markdown 代码块 / toolArgs / toolOutput / diff）：同一底色、同一圆角（`--radius-md` = 8px）、同一 hairline 边框；markdown 代码块增加**头部栏**（语言标签 + Copy），作为一等公民与工具内部的安静小块区分层级。

## 考虑过的选项

- **维持深色代码板、只调圆角**：被否——嵌套时的明暗拼贴是割裂感的主因。
- **给 args/diff 也加头部栏**：被否——工具内部是二级信息，头部栏会放大噪音。

## 后果

- Shiki 回到双主题（`themes: { light: "one-light", dark: "github-dark" }` + `--shiki-dark` 变量切换）。
- diff 色板恢复按主题取值（浅色主题下代码面是暖光底）。
- 折叠预览（max-block-size）只作用于 `<pre>`，头部栏在折叠态仍然可见，块的身份感不丢。
